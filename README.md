# Sistema de Controle de Presença por Localização

Projeto full stack desenvolvido para permitir o registro de presença de alunos por meio da localização do dispositivo.

## Tecnologias

### Frontend

- HTML
- CSS
- JavaScript

### Backend

- Node.js
- Express

### Banco de dados

- PostgreSQL

## Estrutura do projeto

```text
frontend/
backend/
database/
docs/
```
